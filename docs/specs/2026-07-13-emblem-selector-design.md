# 七地区大图标选择功能设计

## 目标

在现有本地图片合成网页中新增“大图标”下拉选择功能。用户可从七个地区图标中选择一个，画布预览立即切换，导出的 PNG 使用当前所选图标。

## 范围

本次仅调整大图标的选择、加载与绘制。上传图片、两行文字、输出尺寸、遮罩颜色、遮罩透明度、图标光晕、画面布局和导出流程保持现有行为。

资源图片已经是透明背景，直接使用其透明通道，不执行抠图、转码或资源重制。

## 用户界面

在左侧控制面板的遮罩/光晕相关设置之后、导出按钮之前添加一个原生下拉框，标签为“选择大图标”。

下拉框按以下固定顺序显示七项，默认选中“蒙德”：

| 显示名称 | 资源路径 |
| --- | --- |
| 蒙德 | `assets/mengdei.png` |
| 璃月 | `assets/liyue.png` |
| 稻妻 | `assets/daoqi.png` |
| 须弥 | `assets/xuni.png` |
| 枫丹 | `assets/fengdan.png` |
| 纳塔 | `assets/nata.png` |
| 空月之歌 | `assets/nuodekalai.png` |

下拉框沿用现有文字输入框的深色视觉样式，并在窄屏布局中保持占满控制面板宽度。

## 数据与渲染流程

页面启动时并行预加载七张图标图片。每张成功读取的图片继续使用现有的透明像素边界计算，以消除图片文件四周透明留白对视觉尺寸的影响。

当前选择由下拉框的值决定。用户切换选项时，页面立即调用现有渲染流程；`drawCenterOverlay` 从已加载图标集合中读取当前资源，并沿用现有图标位置、目标高度、透明度和光晕绘制参数。

导出按钮在导出前仍会重新渲染画布，因此导出的 PNG 与预览中的当前选择一致。

## 加载失败处理

七张图片相互独立加载。单张资源加载失败时：

- 状态栏指出对应名称的图标加载失败；
- 该选项保持在下拉框中，但被禁用，避免用户选择空资源；
- 其他成功加载的图标仍可正常选择、预览和导出；
- 如果默认“蒙德”加载失败，自动选择第一张成功加载的图标；如果七张全部失败，保留无大图标的预览并提示检查 `assets` 目录。

## 验证

1. 静态界面测试确认存在“大图标”下拉框，并且七项的名称、顺序和资源值完全正确。
2. 渲染状态测试确认默认值为“蒙德”，合法选项可写入状态，未知值回退到默认值。
3. JavaScript 语法检查和现有单元测试全部通过。
4. 浏览器冒烟测试依次选择七项，确认画布即时重绘、控制台无错误。
5. 冒烟测试选择至少一个非默认图标后导出，确认下载流程仍可用且预览使用所选图标。

## 不包含的改动

- 不为七个图标增加独立的大小、位置、颜色或光晕参数。
- 不增加缩略图网格、搜索或自定义图标上传。
- 不修改图标源文件。
- 不调整页面其他文字、画面构图或导出文件名。
